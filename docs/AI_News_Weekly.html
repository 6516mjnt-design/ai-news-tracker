本レポートの生成ロジックと自動収集フロー

本ページは、日常のニュース収集・ノイズフィルタリングからLLMによるトピック整理までの自動化手順を検証・運用するテストレポートです。以下に集約パイプラインの構成と検索設計を記録しています。

1. 運用背景とノイズ削減

従来収集におけるノイズ

  • 週数百件単位の記事件数を個別確認・分類する負担
  • 株価・市況・個別製品のPR・プレスリリースなどのノイズ混入

本パイプラインでの対策

  • 主要一般紙・経済紙・専門Webメディアの自動集約
  • 日本語・英語の両対応および概念・トレンドキーワードの最適化
  • LLMを活用した主要3トピックへの構造化と要約整理

2. 収集キーワード（`script.py`）と収集対象メディアの仕様

RSSとの高い互換性と安定取得を確保するため、シンプルな論理和（OR条件）で日英の先端トレンドキーワードを網羅しつつ、ノイズ排除を行っています。

【指定キーワード群（日英対応）】

OpenAI, ChatGPT, Gemini, Anthropic, Claude, Copilot, LLM, 生成AI, 人工知能, フィジカルAI, スーパーインテリジェンス (ASI), 超人工知能, AI安全, AI規制

主要ベンダー・モデル名に加え、次世代の「スーパーインテリジェンス」や「フィジカルAI」、ガバナンス・安全枠組みに関する言及を確実に集約します。

【主な収集対象メディア】

[新聞・一般紙・経済紙] 読売新聞, 朝日新聞, 日本経済新聞, 毎日新聞, 産経新聞 ほか
[IT・テクノロジーメディア] ITmedia, GIGAZINE, CNET Japan, WIRED, Forbes Japan ほか

主要新聞メディアの外交・政策・社会面報道と、IT専門メディアの最先端技術ニュースを並行してカバーします。

【除外パラメータ】

-intitle:株 -intitle:市況 -intitle:株価 -intitle:決算 -intitle:PR -intitle:プレスリリース -intitle:キャンペーン

毎日の株式市況レポート、企業の決算数値、単なる製品宣伝セミナーやPR記事をタイトル判定で自動除外します。

3. パイプライン概要

01
日次自動収集： GitHub Actionsにより `script.py` を毎日実行し、各種RSSフィードから該当ニュースのタイトル・URLを取得。
02
蓄積・ローテーション： URLベースで重複排除を行いながら保存。ストレージ肥大化を防ぐため、30日を超えた過去データは自動破棄。
03
要約・HTML化： 1週間分の集約データをLLMへ投入し、3大トピックへの分類・要約と元記事リンクの紐付けを行ってHTML化。

4. 今後の展開・他分野への応用

本収集・フィルタリング構成の有効性を検証しつつ、今後は「安全保障・輸出管理（BIS規制・経済安保等）」や「エネルギー政策」など、特定の政策・国際情勢テーマへの横展開を計画しています。
